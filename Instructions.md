# Sequence of Development

When I request for solving an issue from Plane PM, you should fetch this issue by the MCP Server and then create a new branch for the sprint and then a branch for the issue as Sprint-x-VANTA-x and when the issue ends you should merge the branch for the issue into the branch for the sprint and if the sprint ends then merge the branch for the sprint into the main branch.

- Each PR should be reviewed by at least one other developer.
- Each PR should be merged only after it has been reviewed and approved by Ahmed Ashour (me).

## Sequence of Development

1. Fetch the issue from the MCP Server.
2. Create a new branch for the sprint.
3. Create a new branch for the issue.
4. Solve the issue.
5. Create a PR for the issue.
6. Review the PR.
7. Approve the PR.
8. Merge the PR.
9. Test the issue.
10. Approve the issue.
11. Merge the issue branch into the sprint branch.
12. If the sprint ends, merge the sprint branch into the main branch.

## Sequence of Development for the Sprint

1. Create a new branch for the sprint.
2. Create a new branch for the issue.
3. Solve the issue.
4. Create a PR for the issue.
5. Review the PR.
6. Approve the PR.
